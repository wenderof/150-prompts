# **App Name**: Vanguarda IA

## Core Features:

- Elite Prompt Repository: An organized, high-fidelity library of 150+ expert commands for content and sales management.
- Live Execution Tool: A tool that uses generative AI to preview exactly how specific commands transform input into professional business copy.
- Smart Category Grid: Premium glassmorphism cards categorized by platform (Instagram, WhatsApp, Ads) with elegant hover states.
- Cinematic Dashboards: Interactive visual simulations of high-performance AI results including ads, captions, and script previews.
- Operational Workflow Timeline: An animated five-step technical roadmap demonstrating the Copy-Paste-Personalize-Generate process.
- Visual AI Sandbox: A playground interface mimicking modern SaaS environments to visualize AI outputs for various business needs.
- Premium Command Portal: A sophisticated user area for managing prompt access and quick-copy functionality for any device.

## Style Guidelines:

- Primary color: Electric Neon Purple (#9D50FF) for high-energy tech branding.
- Background: Ultra-dark Onyx (#0B0B0F) creating a deep cinematic space for elements to pop.
- Accent: Analogous Deep Indigo (#5A42F5) used for glow effects, shadows, and subtle gradients.
- Headline font: 'Space Grotesk' (sans-serif) to evoke a computerized, futuristic startup identity; Body font: 'Inter' (sans-serif) for high readability and professional neutrality.
- Minimalist, thin-line outline icons with subtle purple glows and sophisticated SVG animations.
- Stripe-inspired modular sections with expansive white space, light-leaks, and floating glassmorphism layers.
- Staggered scroll-reveal transitions, magnetic button hovers, and soft rhythmic glows simulating a breathing interface.
